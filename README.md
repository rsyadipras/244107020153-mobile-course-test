```text
## 🛠️ Persyaratan Lingkungan Pengembangan

Untuk menjalankan proyek-proyek Flutter dalam repositori ini di komputer lokal, pastikan perangkat kamu telah terpasang:

- **Flutter SDK:** `>=3.0.0`
- **Dart SDK:** `>=3.0.0`
- **IDE:** VS Code / Android Studio (dengan ekstensi Flutter & Dart)
- **Emulator / Device:** Android Emulator / iOS Simulator / Perangkat Fisik
```
